## 💻 Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

**Note:** Available scripts depend on the project's `package.json`. Configure the required environment variables before using Firebase-dependent features.
